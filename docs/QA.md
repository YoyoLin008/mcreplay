## 独立审查发现的五个问题及修复

1. **两份错误响应误通过**：相同 `isError=true` 现在仍返回 `review`，不将失败解释为兼容。
2. **无观察样本误通过**：没有观察、完全空响应或相同空文本均提示审查，避免覆盖空洞。
3. **匿名动态键的顺序误报**：不能恢复键身份时停止载荷形状比较，保留封装检查并提示审查。
4. **调用与必填 schema 矛盾**：观察只允许 `{}`，声明必填参数时拒绝录入；目录定义仍可用于审查。
5. **平台说明失实**：移除 Windows 快速开始，明确文件安全接口依赖 POSIX，实际仅测试 Linux。

修复后，独立审查者复跑核心和比较测试 **89 passed**，并用对抗性脚本复核上述前四项；第五项核对 README。一次继承旧环境沙箱的 SDK 测试被终止，未计作成功或代码故障；上表 SDK 通过来自当前执行环境中的实际复跑。
