# McReplay / 麦回放 — 产品需求

状态：实现前定义；服务规则审核后采用离线优先方案。2026-10-24 UTC。

**一句话价值：** 将正常麦当劳 MCP 使用得到的结果转换为不含原始值的结构样本，在本地回放并检测适配器依赖的结构变化。

目标用户是维护麦当劳 MCP Skill、解析器和演示应用的个人开发者。目标问题是一次成功的对话无法成为安全、稳定、无需会员 Token 的回归测试。现有通用 CLI 与探测脚本能列举工具和响应，但这不等于可提交到仓库的安全样本或可复现的结构测试。

## 主流程

1. 用户使用符合官方规则的正常 AI MCP 客户端，明确触发一次必要的只读查询；Token 只保留在客户端本地安全配置中。
2. 用户合法导出结果，在本地选择输入。未获得真实结果时可先运行明确标记的合成演示。
3. McReplay 识别响应封装、提取结构并删除原始标量值，输出带来源类别的结构包。不能解析时明确保留“未知文本”类别，不猜业务字段。
4. 开发者比较两份结构包，检查工具消失、必填字段和类型变化等风险；查看本地报告。
5. 用本地 MCP 回放服务将合成样本接入适配器，在 CI 中跑稳定测试；始终标注结构样本不能代表真实金额、日期、库存、资格或会员状态。

## MVP

- 实际可安装的 Python 包与 CLI，官方 MCP SDK 的本地回放协议支持。
- 明确来源类别：合成演示、用户导入；不得将合成数据标成官方实测。
- 输入验证、大小/深度限制、可解释错误、异常退出状态。
- 值删除的结构包；不收集 Token，不持久化原始响应，不将账户数据写入公共演示。
- 响应封装识别与保守结构推断，覆盖 JSON、文本和空结果；无法识别格式时 abstain。
- 结构差异和输入 schema 差异报告，区分破坏性风险、兼容性变化和未知项。
- 本地 MCP stdio 回放；不会转发至官方端点，不提供下单、兑换、领券等状态变更入口。
- 可执行的合成工作流、自动化测试、CI、中文 README、完整 MCP 集成说明。

必要 MCP 场景聚焦官方 `now-time-info`、`campaign-calendar`、`list-nutrition-foods`。它们分别提供时间对象、活动记录和可能为非 JSON 的营养结果，足以验证不同响应形态；不调用账户历史、地址或交易工具。不使用这三个工具并不意味着它们匿名可用，官方访问仍须 Bearer Token。

## 明确不做

不批量/定时调用真实服务；不存储或代理 Token；不抓取会员信息；不提交交易；不提供营养医疗判断；不宣称结构推断是官方 schema；不承诺穷尽 JSON Schema 兼容性；不声称合成回放可以验证真实业务逻辑。

## 可选增强

有测试支撑时再增加本地 HTML 报告、更多响应表示法、Skill 包装和维护者提供的自定义断言。不能牺牲规则合规、真实性标记和测试完整性换取功能数量。

## 验收标准

- 全新环境能按 README 安装并运行离线演示，不需要账户或付费服务。
- 合成的工具删除、必填参数新增、响应字段删除、标量类型变更和空结果变化有对应检测结果。
- 合成隐私哨兵在结构包、报告、日志中不可找到；输入原文不被写入新文件。
- 标准 MCP SDK 客户端能连接本地回放，`tools/list`、`tools/call` 与错误路径通过集成测试。
- CI 不读取真实 Token、不请求官方业务服务；任何未经认证的测试均明确标注。
- 用户能在 30 秒内从 README 理解目标、区别和限制；按命令完成三个真实开发工作流示例。
- 官方强制文件齐全，声明逐字复制；公开仓库和报名状态分别核验。

## 主要风险

| 风险 | 应对 | 仍存在的限制 |
|---|---|---|
| 服务规则禁止自动化访问 | 不做远端脚本采集；正常 AI 客户端显式查询后本地导入 | 主办方仍需判断真实集成是否满足参赛要求 |
| 没有授权 Token | 用标准 SDK 与合成协议双重测试；不伪称 live | 官方真实响应尚未独立验证 |
| 值删除破坏语义 | 强制标记结构回放，保留形态而非业务真实性 | 无法验证价格、时间及资格逻辑 |
| 异构数组/文本导致误报 | 保守分类，显式未知/样本覆盖范围 | 单次样本不能证明完整返回契约 |
| 字段名本身可能含个人信息 | 不提供一键公开发布；限制并清理不安全动态键 | 分享前仍需人工检查本地包 |
| JSON Schema 兼容性复杂 | 清晰列出支持规则；未支持约束列为待审查 | 不是通用形式化兼容性证明器 |

## 发布与成功衡量

首版成功以可复现测试、文档准确和安全演示为准，不以虚构用户量或 Star 为准。只发布一个公开仓库；报名以官方机器人成功回复为证据，获奖/排名不等于资格最终核验。真实用户反馈、有效 Issue 和独立开发者复用是后续检验方向，不是当前已取得成果。
