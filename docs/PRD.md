# McReplay / 麦回放 — 产品需求

日期：2026-10-24。采用本地处理与离线回放架构。

**一句话价值：** 将一次麦当劳 MCP 查询变成可复现的本地结构测试。

## 用户与问题

面向维护麦当劳 MCP Skill、解析器和演示应用的开发者。响应字段、类型或封装发生变化时，开发者需要定位解析失败，并将发现的问题变成可重复运行的回归测试。

## 主流程

1. 用户在 AI 客户端中请求一次只读查询，并保存其结构；已有完整结果时直接使用。
2. McReplay 识别响应封装，提取字段结构，将标量值替换为占位符。
3. 开发者比较两份结构包，在终端或 HTML 报告中定位变化。
4. 本地 MCP 回放将样本送入适配器，CI 根据退出码判断测试结果。

## 产品范围

- Python 包、CLI 与可导入的 Skill。
- `now-time-info`、`campaign-calendar`、`list-nutrition-foods` 的空参数观察。
- JSON、代码围栏、Markdown 后缀、普通文本与空结果识别。
- 工具定义、字段、类型和响应封装的差异检测。
- `breaking`、`review`、`info` 三级结果及对应退出码。
- 标准 MCP SDK 的本地 stdio 接收与回放。
- 输入大小、深度和格式验证；本地文件独占创建。
- 合成演示、自动化测试、CI 和集成文档。

认证由客户端管理，查询由用户明确触发；数据处理和回归测试在本地完成。具体处理规则见 [支持范围](limitations.md)。

## 验收标准

- 在 Linux 和 macOS 的全新环境中按 README 安装并运行演示。
- 工具删除、必填参数新增、响应字段删除、标量类型变更和空结果变化均有检测结果。
- 测试输入中的标量值被替换，输出文件保持私有权限。
- MCP 客户端完成初始化、工具发现、调用、接收与回放。
- CLI、HTML 和 CI 提供一致的比较结果。
- README 能快速说明产品用途，并给出三个可运行的开发工作流。
- 比赛要求的仓库文件齐全，公开仓库与报名状态可查。

## 后续方向

更多响应格式、自定义适配器断言，以及根据开发者反馈完善差异说明。通过有效 Issue、独立复用和解析故障复现来评估产品价值。
