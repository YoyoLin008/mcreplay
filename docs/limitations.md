# 首版限制

| 边界 | 对使用者的影响 |
|---|---|
| 官方认证尚未实测 | 无法确认当前服务端字段、空参契约、地域可达性、401/429 或可用性；合成 SDK 测试不替代 live 验证 |
| 只允许三个空参只读工具 | 适用面集中在时间、活动和营养响应；不能用于订单、券、门店或交易回归 |
| 单次结构观察 | 字段缺失可能来自可选值，空数组没有元素类型证据；变化是风险提示而非服务违约证明 |
| 值被替换 | 金额、日期、营养数据、枚举值及布尔业务逻辑不能通过这些样本验证 |
| 纯文本保守处理 | 不从自然语言、TOON、CSV 或未知表格猜测业务结构；只有表示类型和空/非空差异可供检查 |
| JSON Schema 仅支持部分约束 | 文档、示例及不支持的约束被删除或提示复核；不能得出完整向前/向后兼容结论 |
| 字段名仍可能敏感 | 英文字母/下划线键名会保留，嵌入其中的私密内容也会保留；结构包、工具定义及 HTML 分享前必须检查 |
| `user-import` 非真实性证明 | 文件可能是人为构造或修改；来源标记只表示输入途径 |
| 本地回放不是录屏式复刻 | 返回合成结构，不能证明适配器的实际业务决策正确 |
| 接收服务只写一个新文件 | 为防止覆盖与混入数据，第二次观察需要新路径并重启 |
| 没有远端采集或真实服务 CI | 遵守官方自动化访问限制；不能用本项目监控官方服务在线状态 |
| 参赛核验由主办方决定 | 本地功能可验证，但不保证报名、排名、获奖或集成形式获得认可 |

已有代码级和协议级证据支持本地行为；没有用户访谈、维护工时实验、生产运行记录或社区采纳数据。请据此评估是否适合自己的项目。
