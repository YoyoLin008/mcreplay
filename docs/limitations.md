# 比较规则与支持范围

| 项目 | 当前实现 |
|---|---|
| 工具与参数 | `now-time-info`、`campaign-calendar`、`list-nutrition-foods`，参数 `{}` |
| 比较对象 | 两份观察包中的工具定义、响应字段、类型与封装 |
| 业务值 | 字符串、数字和布尔值统一替换为占位符，比较聚焦结构 |
| 普通文本 | 记录文本类型和空/非空状态，标记为人工复核 |
| 数组 | 比较观察到的元素形态；空数组和混合类型变化进入人工复核 |
| JSON Schema | 检查实现支持的类型、属性和输入约束，其余约束进入人工复核 |
| 动态键 | 替换不符合标识符规则的键；有替换时跳过依赖字段身份的形状比较 |
| 来源 | `synthetic` 表示演示生成，`user-import` 表示导入或本地接收 |
| 回放 | 使用结构包中的占位响应，通过本地 stdio 返回 |
| 接收 | 每次接收服务写入一个新文件，新观察使用新路径并重启 |
| 平台 | Python 3.11+，Linux 和 macOS |

报告中 `breaking` 表示已有解析依赖可能受影响，`review` 表示需要补充样本或人工检查，`info` 表示信息变化。无变化时返回退出码 `0`。

集成验证进度见 [QA 记录](QA.md)，字段名与本地文件的管理见 [安全说明](../SECURITY.md)。
