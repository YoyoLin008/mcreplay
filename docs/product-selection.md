## 为什么选择 McReplay

公开问题和不同代码库重复体现同一维护难点：官方文档无完整 schema；工具名与实时报表可能不同；结果可能是结构化 JSON、Markdown 内 JSON、纯文本或空结果。它们是真实技术证据，但不能据此编造用户规模。

McReplay 面向维护麦当劳 MCP Skill 的独立开发者。它把一次正常使用产生的结果变成删除值的结构样本，为解析器提供可重复的本地回归测试。它不参与比价、配餐或抢券。与通用探测器的边界是：离线输入、显式来源、删除真实值、结构变化分析、可用于 CI 的退出状态和本地 MCP 回放，不遍历业务工具、不猜参数、不把失败自动替换为演示结果。

可直接验证的收益：已知测试变体是否被检测；私密原值是否从输出消失；离线回放是否能被标准 MCP 客户端消费。暂未验证的收益：真实项目维护工时、社区采纳率和所有服务端变更的检出率。

## 服务规则门槛与设计调整

已于 2026-10-24 直接获取 [MCP 服务规则](https://cdn.mcd.cn/cms/pages/MCPServerRules.html)，页面标注版本 2025-12-03。第三条限制批量、高频及自动化调用，第六条明确禁止利用脚本、爬虫或自动化工具调用服务。竞赛开放 Skill 不等于豁免该规则。

因此不发布定时抓取、自动探测、真实服务 CI 调用或批量录制。真实服务应仅由用户在正常 MCP AI 客户端中明确发起最小必要查询，后续在本地处理其合法导出结果。任何直接远端采集功能都需先获得官方明确许可；不能用“只读”替代许可。比赛是否认可该集成形式仍以官方核验为准。
